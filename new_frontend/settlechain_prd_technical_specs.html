# SettleChain Project Requirements Document ## Project Overview SettleChain is a decentralized bounty escrow and settlement system built on the Algorand blockchain. It connects Sponsors, Contributors, and Validators in a trustless ecosystem. ## User Roles & Capabilities ### 1. Sponsors - Connect Algorand wallet (Pera/AlgoSigner). - Create Bounties: Input title, description (auto-hashed), reward (ALGO), and deadline. - Lock funds into a "Reverse Escrow" smart contract. - Review submissions and release funds or initiate disputes. ### 2. Contributors - Browse open bounties with verified on-chain funding. - Submit work with file uploads and automated work hashing. - Track payment status. ### 3. Validators - Resolve disputes via staked voting. - View original brief hashes vs. submission hashes. - Earn rewards for accurate validation. ## Technical Specifications - **Blockchain:** Algorand TestNet (simulated via mock API for demo). - **Security:** Immutable Brief Hashing (SHA-256), ZK Proof of Work concepts. - **Data Storage:** Firebase structure for off-chain metadata (users, descriptions). - **Trust Score:** 0-1000 integer based on successful settlements. ## Key User Flows - **Flow 1 (Happy Path):** Create -> Lock -> Submit -> Approve -> Release. - **Flow 2 (Dispute Path):** Dispute -> Validator Vote -> Majority Payout/Refund. - **Flow 3 (Expiry Path):** Deadline pass -> Auto-refund to Sponsor. ## Design Requirements - **Theme:** Dark mode, Electric Blue accents, Glassmorphism. - **UX:** Demo Mode toggle for pre-filled states, wallet connection modals, loading spinners for "on-chain" transactions.
